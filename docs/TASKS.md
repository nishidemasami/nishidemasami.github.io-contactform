# タスクリスト (MoSCoW分析)

このドキュメントは、プロジェクトのタスクをMoSCoW分析（Must Have, Should Have, Could Have, Won't Have）に基づいて分類・管理するためのものです。AIエージェントおよび開発チームが次に何を行うべきかを明確にします。

## Must Have（必須・最優先）
- [ ] **フロントエンドの単体テスト導入**: `testpage`（Next.js）における単体テストフレームワーク（Vitest または Jest / React Testing Library）の導入と、基本コンポーネントのテスト作成（現状、`package.json` に単体テストの仕組みが不足しているため明らかな問題として追加）。

## Should Have（推奨・高優先）
- [ ] **バックエンドAPIのバリデーション強化**: OpenAPI仕様に準じたリクエストパラメータの厳密な検証処理の実装。
- [ ] **カバレッジレポートの可視化**: バックエンド（tarpaulin）およびフロントエンドのテストカバレッジレポートを継続的に収集し、Wiki等で閲覧できるようにする。

## Could Have（可能であれば・低優先）
- [ ] **CI/CDパイプラインの拡充**: ステージング環境への自動デプロイとE2Eテストの組み込み。
- [ ] **フロントエンドのUIコンポーネント拡張**: 新規要件に合わせたStorybookコンポーネントの追加実装。

## Won't Have（今回は見送り）
- [ ] **別クラウドプロバイダーへの移行**: AWS環境からGCP/Azureなどへのインフラ移行は、現在のスコープ外とする。
