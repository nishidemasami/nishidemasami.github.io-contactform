# タスクリスト (MoSCoW分析)

プロジェクトにおける AI 自律的作業と今後の開発に向けたタスクリストです。

## 🟩 Must have (必須)
- **ドキュメントの補完**: `api/README.md` および `testpage/README.md` の `[WIP]` となっている箇所（各ソースの説明など）を追記し、完了させる。
- **自律的 AI エージェント用指示書の作成**: リポジトリルートに `AGENTS.md` を配置し、AIが自律的に作業を行う際のコーディング規約やドキュメント参照先（`docs/`ディレクトリなど）を定義する。
- **PR テンプレートの導入**: `.github/pull_request_template.md` を作成し、AI や人間が PR を作成する際の標準的なフォーマットを定義する。

## 🟨 Should have (推奨)
- **E2E テストの導入**: フロントエンド (`testpage`) の機能を担保するための E2E テスト (例: Playwright や Cypress) を追加する。
- **API の結合テスト追加**: バックエンド API のエンドツーエンドまたは結合テストを拡充する。
- **各自動化スクリプトの整理**: CI/CD (GitHub Actions) 実行時の重複処理などをリファクタリングし、効率化を図る。

## 🟦 Could have (可能であれば)
- **フロントエンドの UI/UX 改善**: エラーメッセージの明確化やローディング表示の最適化など。
- **依存パッケージの自動更新設定**: Dependabot または Renovate を導入し、`pnpm` や `cargo` の依存関係を自動で最新に保つ仕組みを構築する。

## 🟥 Won't have (今回は見送り)
- **別プラットフォームへの移行**: 現在の AWS (Cognito, Lambda, Aurora) 構成から別クラウド環境への移行。
- **過度なリファクタリング**: 現在正常に稼働しているコアロジックに対する、機能追加を伴わない大規模なリファクタリング。
